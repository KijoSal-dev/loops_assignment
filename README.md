# loops_assignment
a short assignment from Tech4Dev to better understand loops

***Loops Assignment – Python***
__Overview__
This assignment focuses on using loops in Python to perform various tasks. It demonstrates the use of:

- for loops
- while loops
- break statements
- Iterating over lists, strings, and numeric ranges

The goal is to understand how loops control the flow of a program, handle conditions, and interact with user input.

__Tasks__
1. Count scores greater than 50
Task: Given a list of scores, count how many are greater than 50.
Concepts: for loop, if condition, incrementing a counter.

2. Print numbers from 10 down to 1
Task: Print numbers in reverse order.
Concepts: while loop, decrementing a counter.

3. Print each character of a string
Task: Given a string, print one character at a time.
Concepts: Iterating over strings with a for loop.

4. Stop a loop when a specific number is found
Task: Stop printing numbers when encountering 7 in a list.
Concepts: for loop, break statement.

5. Print numbers from 1 to 10
Task: Print numbers sequentially from 1 to 10.
Concepts: for loop and while loop, incrementing counters.

6. Print each name in a list
Task: Iterate through a list of names and print each.
Concepts: for loop, list iteration.

7. Keep asking user for input until 0 is entered
Task: Continuously prompt the user for numbers until they input 0.
Concepts: while loop, user input, conditional termination.

8. Loop starting at 1 and increasing by 2 until 10
Task: Print numbers starting from 1, increasing by 2, up to 10.
Concepts: while loop, step increment, conditional stopping.

__Key Python Concepts Covered__

1. for loops – iterating over lists, strings, and ranges.
2. while loops – looping based on a condition.
3. break statements – stopping a loop prematurely.
4 Conditional statements – using if to control flow.
5. Incrementing/decrementing counters – count += 1, count += 2, count -= 1.
6. User input – using input() and converting to int.

__Usage__

1. Clone or download the Python script.
2. Run each task separately in your Python environment.
3. Follow on-screen prompts for tasks requiring user input.
